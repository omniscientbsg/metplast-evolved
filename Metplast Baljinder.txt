## 7. LIGHT / DARK MODE — full spec (new requirement)

The same website must run in **both light and dark mode.** Build it once with tokens; do not hardcode colours.

### 7.1 Method
1. Use **CSS custom properties (design tokens)** on `:root` for dark (default) and `[data-theme="light"]` for light. (Next.js: `next-themes` with `attribute="data-theme"` is the clean route.)
2. **No raw hex anywhere in components.** Components reference tokens only (e.g. `background: var(--bg)`).
3. **Toggle in the header**, left of "Get a Quote". Sun/moon icon, min 44×44px tap target.
4. **Default = dark** (matches current look). Respect OS `prefers-color-scheme` on first visit, then remember the user's choice (persisted).
5. Smooth ~200ms transition on background/text/border; **no transition on images**.

### 7.2 Token table — set both

| Token | Dark (default) | Light |
|-------|----------------|-------|
| `--bg` | `#0B1220` | `#FFFFFF` |
| `--bg-elevated` | `#121A2B` | `#F5F7FA` |
| `--surface` | `#162032` | `#FFFFFF` |
| `--text` | `#E6ECF5` | `#1A2430` |
| `--text-muted` | `#9AA7BD` | `#5A6678` |
| `--border` | `rgba(255,255,255,0.10)` | `rgba(16,24,40,0.10)` |
| `--brand-navy` | `#1B3A6B` | `#1B3A6B` |
| `--accent` | `#F97316` | `#F97316` |
| `--accent-text` | `#FFFFFF` | `#FFFFFF` |
| `--glass-bg` | `rgba(255,255,255,0.06)` | `rgba(255,255,255,0.55)` |
| `--glass-border` | `rgba(255,255,255,0.14)` | `rgba(16,24,40,0.08)` |
| `--glass-blur` | `16px` | `16px` |
| `--shadow` | `0 8px 30px rgba(0,0,0,0.40)` | `0 8px 30px rgba(16,24,40,0.10)` |

### 7.3 Things that must adapt per theme
- **Hero images:** they carry white text. In light mode, keep a **dark gradient scrim** behind hero text so it stays readable over the photo (don't flip hero text to dark). Hero text stays light in both themes; only the surrounding page chrome flips.
- **Logo:** confirm the logo reads on both white and dark. If the current logo is light-only, supply a dark-ink variant for light mode (swap by theme).
- **Liquid Glass:** uses `--glass-bg` / `--glass-border` tokens, so it auto-flips (frosted-dark in dark, frosted-light in light). See §12.
- **Spec tables / cards / forms:** all driven by `--surface`, `--text`, `--border` → adapt automatically.
- **Accent orange and brand navy do not change.**

### 7.4 QA checklist (both themes)
Text contrast AA in both · toggle persists on reload · respects OS default on first visit · no white flash on load in dark mode · glass readable in both · hero text readable in both · logo visible in both.

## 12. Liquid Glass (per theme)

Apply only after structure is correct. Recipe uses tokens so it flips with theme:
`background: var(--glass-bg); backdrop-filter: blur(var(--glass-blur)) saturate(120%); border:1px solid var(--glass-border); box-shadow: var(--shadow); border-radius:16–24px;`

Use on: header nav · hero panel · product selector cards · calculator cards · brochure cards · contact form panel · sticky in-page nav · gallery lightbox.
Do NOT use on: long paragraphs · dense spec tables · footer text · tiny buttons.
Caveats: `backdrop-filter` is GPU-heavy — provide a solid-colour fallback (`@supports not (backdrop-filter: blur(1px))`) and test on a budget Android; keep AA contrast in both themes; don't stack many glass layers per screen.
