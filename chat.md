# METPLAST WEBSITE PHASED EXECUTION PLAN FOR BALJINDER

## 1. Executive Summary for Baljinder

This document is the working execution plan for the new Metplast website.

The current website direction looks visually premium, but the structure, content, navigation, and product logic are not yet correct. The website should not feel like a futuristic tech demo. It should feel like a serious poultry housing and farm systems company with premium engineering clarity.

The biggest decision is this:

Metplast is not only a cage manufacturer anymore.

Metplast must be presented as a complete poultry housing and turnkey systems manufacturer.

Core positioning:

> From levelled land to a complete poultry housing system.

Meaning:

The farmer gives levelled land. Metplast designs, manufactures, integrates, and supplies the poultry housing system on top of it.

This includes housing, cages, feeding, drinking, manure removal, egg collection, ventilation, cooling pads, curtains, false ceiling, silos, calculators, brochures, and enquiry flow.

Baljinder should not start with random design polishing. First fix the website architecture.

---

## 2. Website Aim

The website must help four types of visitors quickly understand Metplast:

1. Farmers planning a new poultry project.
2. Dealers trying to understand product categories.
3. Consultants comparing systems for clients.
4. Serious buyers who want brochure, calculator, and enquiry flow.

The website should answer these questions fast:

1. What does Metplast manufacture?
2. Can Metplast build the complete poultry housing system?
3. What solutions exist for Layer, Broiler, and Breeder farms?
4. Where does pullet fit?
5. What common systems are available across all farm types?
6. How can the user calculate requirement?
7. How can the user download brochure or enquire without friction?

## 15. Brochure Download Logic

Brochure download must be fast.

Do not ask a full lead form for brochure download.

### Required logic

Ask only email OR phone number.

Fields:

1. Email.
2. OR.
3. Country Code + Phone Number.

Validation:

1. User must fill either email or phone.
2. If phone is filled, country code is required.
3. If email is filled, phone is optional.
4. If neither is filled, show error:

> Enter email or phone number to download brochure.

### Phone placeholders

Country Code:

> +91

Phone Number:

> 9876543210

### Download behaviour

After valid entry, download should start immediately.

Do not make user wait for approval.

### Hidden tracking fields

Capture:

1. Brochure name.
2. Product category.
3. Page URL.
4. UTM source.
5. Download time.

## 17. Liquid Glass Implementation Map

Use Liquid Glass selectively.

### Use Liquid Glass for

1. Sticky transparent header.
2. Hero overlay panel.
3. Product selector cards.
4. Calculator cards.
5. Brochure cards.
6. Contact form panel.
7. Sticky in-page navigation.
8. Gallery lightbox overlay.

### Do not use Liquid Glass for

1. Long paragraphs.
2. Dense specification tables.
3. Footer text.
4. Very small buttons.
5. Anything that reduces readability.

### Rule

Structure first. Glass effect later.

Do not spend time polishing glass UI before sitemap, content logic, product hierarchy, and forms are correct.
